# Magora node runtime — fully pinned.
#
# WHY EVERY TRANSITIVE DEP IS PINNED, not just the seven we import:
#
# On 2026-08-11 librosa 1.0.0 was published. It dropped `audioread` from its dependencies.
# `birdnetlib` imports audioread at module scope (birdnetlib/main.py: `import audioread`) but does
# NOT declare it — it had always arrived transitively via librosa. So from 2026-08-11 onward, every
# node that ran the unpinned `pip install librosa birdnetlib` got librosa 1.0.0, no audioread, and
# died at `from birdnetlib import Recording` with ModuleNotFoundError. birdnet.service crash-looped
# and the node never sent a heartbeat.
#
# Nothing in this repo changed. An upstream release broke every new node, two days before a steward
# tried to build one. That is what unpinned installs buy you, and it is why this file exists: a
# node's environment must be a function of this repo alone, never of what PyPI happens to serve on
# the day someone flashes a card.
#
# Two consequences encoded below:
#   1. audioread is pinned EXPLICITLY, not left to arrive as somebody else's transitive dep.
#      birdnetlib's undeclared import makes it a direct dependency of ours in practice.
#   2. librosa is held below 1.0. 0.11.0 still declares audioread and is the last line that does.
#
# RESOLVED AND VERIFIED FOR: CPython 3.13, linux aarch64 (Raspberry Pi OS trixie, the pinned base
# image in .github/workflows/build-image.yml). Every entry has a prebuilt manylinux aarch64 wheel on
# PyPI — the image build installs with --only-binary=:all: so a missing wheel fails the build loudly
# instead of silently starting a 40-minute source compile on a Pi.
#
# Verified 2026-08-13: with this set, `Analyzer()` loads the BirdNET model and analyzes a recording
# under numpy 2.5.2. The "NumPy 2.x breaks the model load" note in worker/requirements.txt applies to
# the old `tflite-runtime` package, which the worker uses; nodes use `ai-edge-litert`, which is
# numpy-2 clean. Do not copy the worker's numpy<2 pin here — numpy 1.x has no cp313 wheels at all.
#
# TO CHANGE A VERSION: re-resolve the whole set for cp313/aarch64 wheels-only, don't hand-edit one
# line. A single bumped pin can drag a transitive dep somewhere this file no longer describes.
